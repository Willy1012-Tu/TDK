第二／第四關機構與第三關待機：錯誤處理與排查

src/test_controller.cpp 的 fail() 鎖存 Fault，取消步驟、切關及 RAM 待套用，
停止所有伺服緩移，僅對已接線 ID6/7 送 F7 停止和 F3 00 停用；ID4/5不發送任何封包。
CAN write 拒收時，每 TX_RETRY_MS 重試尚未送入佇列的停止／停用指令。
停止或 Fault 後須確認機構並重啟；五顆已附掛伺服全部detach，PWM關閉；status保留最後指令值，不自動恢復動作。

觸發條件 → 行為
- Servo attach、IntervalTimer 或 worker 建立失敗：初始化停止。
- 任一軸 8C/F3 回報 00：立即停止全部軸；後續 01 不可覆蓋失敗。
- 8C/F3 首次成功入列後，每 STARTUP_ACK_RETRY_MS（500ms）重送尚未確認的設定。
  每條設定總 ACK 期限為 STARTUP_ACK_TIMEOUT_MS（10000ms），重送不延長期限。
  STARTUP_RETURN_ZERO=true；兩軸ID6/7的8C/F3全部確認ACK01後，同批向兩顆送91。
  兩顆各自收到開始及完成回報後才Ready，不因一顆先完成就開放動作。
  Pin3不attach；ID4/5不參與開機檢查。任何有效軸的設定或尋零期限到期仍會停止。
- 91/FE 成功入列後不重送；其 01／02 順序與原 START_TIMEOUT_MS／FINISH_TIMEOUT_MS 保護不變。
- 同批設定回報先失敗後成功：失敗不被後續成功覆蓋。
- 91 回報 00；FE 回報 00、03、05：停止全部軸。
- 任一軸未在 START_TIMEOUT_MS 收到 01，或未在 FINISH_TIMEOUT_MS 內完成：停止。
- 有效ID6/7與五顆伺服可平行，各自完成後同步放行；非法ID4/5與Pin3直接拒絕。
- 第一顆指令 CAN 佇列拒收：只重試未成功入列的指令，超過 TX_TIMEOUT_MS 停止。
- 非 ID6/7、extended、remote、非3-byte回報或校驗錯誤：忽略。
- 02 先於本次 01 或錯誤指令種類：忽略；沒有時間推測到位。
- 已確認的絕對位置等於 FE 目標：維持位置，不發送零距離指令；91仍重新執行。
- busy／boot／fault 收到 NEXT/RUN/HOME：拒收，不排隊。
- 第三關停用，只允許delay0；Next/Run/Home無運動，Debug與RAM致動器注入被拒絕。
- 切出第三關即切換，沒有Park封包或Pin3輸出。
- 非法 Web 參數／模式／動作／node／pin：拒收且保留原設定。
- RAM 缺少封包、重複平行致動器、缺少同步等待、子編號不連續：commit拒絕。
- Upload 逾時：取消傳輸，保留有效 RAM bank；STOP隨時有效。
- YAML 未知欄位、重複欄位、非法坐標／時間／node／pin：產生器失敗並指出設定位置。

連線與路徑
先以 @1 hello 或 @1 status 確認 firmware_id=Stage4_Mechanism_Test、
firmware_revision=stage2-id67-home-v1、startup_return_zero=true；編譯成功不代表已燒錄。
startup_phase、startup_node、startup_command、startup_attempts 可指出卡住的設定／尋零階段。
Serial notice 顯示 ID、指令碼及設定嘗試次數；拒絕、佇列逾時、ACK 逾時及各軸尋零
開始／完成逾時會列出原因。Fault 後須重新啟動，不會以其他按鍵繼續未完成的開機。
position_known_mask 的 bit0／1／2／3 固定對應 ID4／5／6／7；收到實際91或FE完成回報才設位。
預設position6/7=0且mask0表示尚未確認；ID6先完成為mask4，ID7先完成為mask8。
兩顆均尋零完成後position6/7=0、mask12並Ready；沒有時間推測到位。
確認CAN1 1Mbps、已接線ID6/7、電源、終端電阻、收發器及checksum。
91 GoHome 依各驅動器既有參數尋零，不修改尋零方向、速度與感測器設定。
PWM 伺服以計時／脈寬判定完成，沒有實際到位感測回授。
CAN write 成功表示進入主控佇列，故障時仍須確認實際硬體狀態。
